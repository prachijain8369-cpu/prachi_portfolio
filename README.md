# Prachi Jain — Personal Portfolio

A static personal portfolio built with plain **HTML, CSS and JavaScript**. No framework, no build step, no backend and no API keys.

## What's inside

```
index.html                  page structure and content
styles.css                  all styling (cream / lavender / purple / sage palette)
script.js                   mobile menu + gentle scroll reveals

assets/                     the four photos used on the site
```

## Preview locally

The simplest way: double-click `index.html` to open it in your browser.

Or, to serve it like a real website (needs Python):

```bash
cd prachi-portfolio
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages (free)

This site is **not deployed yet**. You get a live link only after you push the files and switch Pages on:

1. Create a new **public** repository on GitHub (for example `portfolio`, or `prachijain8369-cpu.github.io` for a root URL).
2. Upload everything in this folder so that `index.html` sits at the **root** of the repo (not inside a subfolder). Keep the `assets/` folder.
3. In the repo, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose branch **main** and folder **/ (root)**, then **Save**.
5. Wait a minute or two. GitHub shows your live URL at the top of the Pages screen, usually `https://prachijain8369-cpu.github.io/<repo-name>/`.
6. Open the live URL **and** the repo link in a private/incognito window to confirm both work without logging in.

Submit two links: the **live site URL** and the **public GitHub repo URL**.
